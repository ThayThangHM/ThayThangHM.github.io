IS THE OPERATING SYSTEM A DEVICE PLUGGED INTO YOUR COMPUTER?

Hệ điều hành có phải là một thiết bị được gắn vào máy tính không?

NO — it is SOFTWARE.Không. Hệ điều hành là phần mềm, không phải thiết bị (phần cứng).
Concept 1 · Khái niệm

THE OS IS THE FIRST SOFTWARE INSTALLED ON A COMPUTER.

Hệ điều hành là phần mềm đầu tiên được cài đặt trên máy tính.

No other software can run until at least one OS is installed.

Các phần mềm khác chỉ hoạt động được sau khi máy tính đã cài ít nhất một hệ điều hành.

Function 1 · Chức năng 1
MANAGES HARDWARE DEVICESQuản lí các thiết bị phần cứng

The OS controls the keyboard, mouse, screen, printer…

Hệ điều hành điều khiển bàn phím, chuột, màn hình, máy in…

Function 2 · Chức năng 2
RUNS PROGRAMS & PROVIDES THE INTERFACETổ chức chạy chương trình & cung cấp giao diện
  • Organizes and runs computer programs · tổ chức thực hiện các chương trình máy tính
  • Gives the environment for you to run apps · cung cấp môi trường để chạy phần mềm ứng dụng
  • Provides the interface between you and the computer · cung cấp giao diện giữa người dùng và máy tính

Quick check · Kiểm tra nhanh

1 · Which of these is NOT an operating system?

Phần mềm nào sau đây không phải là hệ điều hành?

C — Windows Explorer is a file-manager app that runs inside Windows, not an OS itself. Windows Explorer là ứng dụng quản lí tệp chạy bên trong Windows, không phải hệ điều hành.

Quick check · Kiểm tra nhanh

2 · Which task is NOT a job of the operating system?

Chức năng nào sau đây không phải của hệ điều hành?

B — editing an image is a job for application software (e.g. Paint), not the OS. Chỉnh sửa ảnh là việc của phần mềm ứng dụng (như Paint), không phải hệ điều hành.

CORE NOTES
Ghi bài — Phần 1: Hệ điều hành
  1. Hệ điều hành (Operating System) là phần mềm, không phải thiết bị phần cứng.
    Là phần mềm đầu tiên được cài trên máy tính; các phần mềm khác chỉ chạy được sau khi có hệ điều hành.
  2. Chức năng: quản lí thiết bị phần cứng và tổ chức thực hiện các chương trình, cung cấp giao diện cho người dùng.
  3. Ví dụ: Windows, macOS, Linux (máy tính); Android, iOS (điện thoại, máy tính bảng).

APPLICATION SOFTWARE

Phần mềm ứng dụng

Software that helps you do a specific job.
Phần mềm giúp em thực hiện những công việc cụ thể.

Concept · Khái niệm

ONE APP, ONE JOB.

Mỗi phần mềm ứng dụng phục vụ một công việc cụ thể.

Word — soạn thảo văn bản
Windows Media Player — nghe nhạc, xem phim
Paint — vẽ hình
Trình duyệt web (Firefox, Chrome…) — xem web

Some apps run online from the Internet; others must be installed on the disk first. Có phần mềm chạy trực tuyến từ Internet, có phần mềm phải cài lên đĩa cứng mới dùng được.

Concept · Khái niệm

EACH APP READS ITS OWN FILE FORMAT — THE EXTENSION TELLS YOU WHICH.

Mỗi phần mềm xử lí một định dạng tệp riêng, nhận ra nhờ phần mở rộng — các kí tự sau dấu chấm cuối cùng trong tên tệp.

Practice · Luyện tập

1 · Which one below is application software?

Trong các phần mềm sau, đâu là phần mềm ứng dụng?

A — Gmail is an email application. Windows 8 and Linux are operating systems. Gmail là phần mềm ứng dụng gửi thư điện tử. Windows 8, Linux là hệ điều hành.

Practice · Luyện tập

2 · Which file extensions open in a media player?

Phần mềm nghe nhìn (media player) mở được các loại tệp có phần mở rộng nào?

B — .mp3 is audio, .avi is video: exactly what a media player plays. .mp3 là âm thanh, .avi là video — đúng loại tệp phần mềm nghe nhìn xử lí.

Apply · Vận dụng

WHY MATCH THE OS WHEN DOWNLOADING SOFTWARE?

Khi tải Scratch để cài lên máy tính, tại sao cần chọn phiên bản phù hợp với hệ điều hành của máy?

So the software runs smoothly and is compatible. The wrong version may fail to run — or even harm the computer. Để phần mềm hoạt động trơn tru, tương thích với máy. Nếu tải sai phiên bản, phần mềm có thể không chạy được, thậm chí ảnh hưởng đến máy tính.

CORE NOTES
Ghi bài — Phần 2: Phần mềm ứng dụng
  1. Phần mềm ứng dụng (application software) giúp thực hiện một công việc cụ thể: soạn văn bản, nghe nhạc, vẽ, xem web…
  2. Mỗi phần mềm xử lí một định dạng tệp riêng, nhận biết qua phần mở rộng sau dấu chấm cuối trong tên tệp. Ví dụ: .docx, .jpg, .exe, .sb3.
  3. Khác hệ điều hành: phần mềm ứng dụng không bắt buộc cài, chạy bên trong môi trường hệ điều hành, cần chọn đúng phiên bản phù hợp hệ điều hành.

TODAY I LEARNED…

  • The OS is software, not a device — the first software a computer needs to run anything else.

  • Application software does specific jobs; the file extension tells the computer which app to use.
