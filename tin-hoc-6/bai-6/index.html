Explain · Hình 3.1 · Minh hoạ một website
📄
Web page
Trang web = một trang siêu văn bản, có địa chỉ truy cập riêng.
→

⌂

Trang chủ: trang mở ra đầu tiên; địa chỉ trang chủ = địa chỉ website.
▢
Website
Tập hợp các trang web liên quan, truy cập qua một địa chỉ; do một người hay tổ chức quản lí.
Key idea · Mạng thông tin toàn cầu

All websites on the Internet, linked together = the World Wide Web (WWW).

Hệ thống các website trên Internet tạo thành mạng thông tin toàn cầu — như một mạng nhện khổng lồ bao trùm thế giới.
⚠️
WWW ≠ Internet
WWW là một dịch vụ trên Internet (bên cạnh thư điện tử, tìm kiếm…).

https://vi.wikipedia.org/wiki/Internet
→ địa chỉ một trang web về Internet, nằm trong website đó

How to · Để truy cập một trang web, ta cần làm thế nào?

OPEN A WEB PAGE IN 3 STEPS

  1. Double-click the browser icon
    Nháy đúp chuột vào biểu tượng trình duyệt.
  2. Type the address in the address bar
    Nhập địa chỉ trang web vào ô địa chỉ.
  3. Press Enter ⏎
    Nhấn phím Enter.
🧭
Then click links to move between pages = browsing the web.
Nháy chuột vào liên kết để chuyển tới trang khác. Di chuyển theo các liên kết gọi là duyệt web.

WHAT SHOULD YOU REMEMBER?

1
Web pages are joined by links
Thông tin trên Internet: trang web (siêu văn bản) nối với nhau bằng liên kết.
2
Website = related pages, one address
Website: các trang liên quan; địa chỉ trang chủ = địa chỉ website.
3
WWW = all websites, linked
Mạng thông tin toàn cầu — một dịch vụ trên Internet.
4
Browser: address → Enter → links
Trình duyệt: nhập địa chỉ, Enter, nháy liên kết để duyệt web.
